Recomendaciones

Recomendaciones para programar.

Leer otros códigos, al leer diferentes códigos, puedes aprender nuevas técnicas y soluciones que quizás no habías considerado.

Hacer revisiones de código, un compañero revisa el código que escribiste para ver si hay errores o si se puede mejorar, esto para mejorar tanto la calidad del código como las habilidades.

Mantenerse actualizado debido a que la tecnología avanza muy rápido, sigue blogs y canales de YouTube para estar saber qué pasa.
